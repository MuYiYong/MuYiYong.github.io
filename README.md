# AboutMe

基于个人简历生成的静态个人主页，定位为图数据库专家与产品战略负责人个人品牌站。

## 文件说明

- `index.html`：主页结构与双语内容
- `styles.css`：视觉样式、区块层次与响应式布局
- `script.js`：语言切换、导航高亮与平滑滚动

## 本地预览

直接在浏览器打开 `index.html` 即可。

如需启动一个本地静态服务，可在当前目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
